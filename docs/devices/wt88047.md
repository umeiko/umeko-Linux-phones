# 红米 2（wt88047）

小米 2015 年发布的百元机，MSM8916 生态里支持度最好的机型之一，
也是本项目的首发机型和 CI 基准机型。

## 硬件参数

| | |
| --- | --- |
| 型号 | 红米 2 / 2A 增强版（HM2014811 等，Wingtech 代工） |
| SoC | 高通 MSM8916（4× Cortex-A53 @ 1.2GHz） |
| GPU | Adreno 306 |
| 屏幕 | 4.7" 1280×720 IPS |
| 内存/存储 | 1~2GB RAM / 8~16GB eMMC，支持 SD 卡 |
| 基带/WiFi | 高通基带 + WCN3620（WiFi/BT/FM） |
| 串口 | UART（ttyMSM0，需拆机 TTL）、USB gadget 串口（ttyGS0） |

## 支持状态

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 屏幕显示/背光 | ✅ | lk2nd simplefb 接管开机画面，面板模块进系统后加载 |
| 触摸屏 | ✅ | rmi4，需 `auto_rmi4_reload` 服务重载驱动（已内置） |
| WiFi | ✅ | 固件由 `umeko-modem-firmware` 服务开机从 modem 分区自动提取 |
| USB 串口控制台 | ✅ | configfs gadget（usb-gadget.service），插上电脑免密进 shell（autottyGS0），同时出 usb0 网卡（192.168.100.1，可 SSH） |
| UART 控制台 | ✅ | ttyMSM0 115200 |
| SSH / webssh | ✅ | SSH 22 端口；webssh 网页终端 8888 端口 |
| USB CAN（gs_usb） | ✅ | 模块内置，`autocanup` 服务自动拉起 can0（500k） |
| 基带/通话 | ❌ | 未做（modem 在设备树里关闭） |
| 摄像头 | ❌ | 未做 |

## 构建产物

CI 每次出一个 extlinux 合并包（`umeko-wt88047+vivo-y23l-*-extlinux.zip`，同时支持
红米2 和 vivo Y23L）：bootfs.img（ext2）刷 system 分区，rootfs 刷 userdata，
见 [extlinux 路线](../extlinux.md)。

legacy 的 mkbootimg 单机型包（boot.img 刷 boot 分区）CI 不再构建，需要时本地跑
`scripts/pack.sh devices/wt88047.env`。

刷机步骤见[刷机与日常使用](../flashing.md)。

## 已知边界

- **USB gadget 已改 configfs 方案**：不再内建 g_serial（它开机独占 USB 控制器，
  阻断 OTG 角色切换），改由 usb-gadget.service 开机组装 acm+ncm 复合 gadget。
  详见 [KlipperPhonesLinux #36](https://github.com/umeiko/KlipperPhonesLinux/issues/36)
- 首次开机较慢（生成 SSH host key），等一两分钟
- 刷机包不附带高通 WiFi/基带固件（不可再分发），首次开机自动从本机
  modem 分区提取；刷机前**不要**乱动 modem 分区
